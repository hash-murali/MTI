# Changelog

## 1.1.0 — Product workflow upgrade

- Added Suggestions, Saved, Random, Preferences, Calibration, Catalog, Add Entry, and Taste Profile tabs.
- Added preset recommendation profiles for Balanced, Focus, Comfort, Deep Story, and Discovery.
- Added saved-queue and random-pick APIs.
- Added user-created catalog entries with descriptions, multiple genres, tags, taste signals, downsides, language, runtime, commitment, and availability fields.
- Added genre evidence view showing overlapping catalog examples.
- Split taste-profile presentation into global and media-specific sections.
- Expanded catalog search to descriptions, tags, and genre evidence.
- Modernized the responsive browser interface.
- Added the MTI v1.1 phased roadmap.
