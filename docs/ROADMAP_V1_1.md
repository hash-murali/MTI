# MTI v1.1 Product Upgrade

This roadmap captures the first major usability upgrade after the initial MVP.

## Phase 1 — Navigation and discovery
- Add Saved, Random, Suggestions, Preferences, Calibration, Catalog, Add Entry, and Taste Profile views.
- Organize recommendation results by category.
- Add profile presets for Focus, Comfort, Discovery, Deep Story, and custom mixes.

## Phase 2 — Catalog ownership
- Add a guided form for user-created media entries.
- Support multiple built-in and custom genres per item.
- Store a standard descriptive paragraph, common metadata, tags, features, and downsides.
- Show genre evidence and overlapping genre membership.

## Phase 3 — Taste intelligence
- Separate global taste, preset/context taste, and media-specific taste.
- Improve calibration controls, custom dimensions, and evidence visibility.
- Add richer feedback and pairwise calibration.

## Phase 4 — Quality and automation
- Add migrations, validation, expanded tests, CI, and release notes.
- Introduce external metadata providers only after the manual workflows are proven.
